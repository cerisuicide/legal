一隅支持

一隅是一款在本机处理电子书的 macOS 状态栏阅读器。

常见问题

  • 通过“导入电子书”选择 EPUB、TXT、MOBI、AZW 或 AZW3 文件。
  • 从菜单栏图标打开阅读窗口，可以按章节阅读、查找和复制文字。
  • MOBI、AZW 和 AZW3 不支持 DRM、Print Replica 或 KFX。

联系开发者

如果遇到问题，请在 GitHub 仓库提交 Issue，并附上 macOS 版本、文件格式和可复现步骤。请不要上传包含个人信息的书籍文件或截图。

提交支持请求

隐私

一隅不收集或上传书籍内容、阅读进度和设置。详细说明请查看一隅隐私协议。
